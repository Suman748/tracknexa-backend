# TrackNexa Backend

Express + Prisma backend for TrackNexa, with phone/OTP auth, location sharing, and live location tracking. SMS OTPs are sent via Twilio.

## Run locally

```bash
git clone https://github.com/Suman748/tracknexa-backend.git
cd tracknexa-backend
npm install
```

Create a `.env` file (not included, for security):
[200~
Then:

```bash
npm run dev
```

Open the Local link it prints (usually http://localhost:5173). The backend (tracknexa-backend) must be running first.
